# 🩴 Bakiak Jaya RL

**Bakiak Jaya RL** is a 3D web-based game inspired by the traditional Indonesian wooden clog racing competition (*Lomba Bakiak*), built using **Three.js** and **Tailwind CSS**. Developed collaboratively by **Tina, Serin, and Luna**, players must coordinate left and right steps in rhythm to race against AI opponents and cross the finish line first!

## ✨ Key Features
* **Rhythm-Based Gameplay:** Tap/press left and right alternating keys carefully to maintain speed and avoid falling.
* **Diverse Environments:** Choose from Kampung Merah Putih, Alun-Alun Kabupaten, Tropical Beach, or Mountain Village.
* **AI Difficulty Levels:** Race against Kids, PKK Mothers, RT Fathers, or Youth Organizations (Karang Taruna).
* **Upgrade Shop:** Spend earned coins to upgrade wood lightness and strap flexibility.
* **Immersive 3D & Audio:** Powered by Three.js graphics and Web Audio API sound effects.
